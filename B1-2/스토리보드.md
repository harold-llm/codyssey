
# 🏃 달립군 (DRG) — 브랜드 광고 영상 기획문서

> 솔로 러너 커뮤니티 플랫폼 "달립군" 10초 브랜드 광고 스토리보드
> 컨셉: 원 컨티뉴어스 줌아웃 (One Continuous Zoom-Out, No Cuts)

## 1. 브랜드 아이덴티티

| 항목 | 내용 |
|---|---|
| 브랜드명 | **달립군** (DRG) |
| 네이밍 의도 | 삼중 의미의 언어유희 — ① **"달리고 싶군", "달리기 마렵군"**: 달리고 싶은 욕구의 감탄형 표현 ② **독립군 라임**: 각자 독립적으로(혼자) 달리는 러너 ③ **군(軍) = 연합**: 함께 모이면 하나의 군대가 되는 솔로 러너 연합 |
| 서비스 정의 | 혼자 달리는 러너들을 느슨하게 연결하는 솔로 러너 커뮤니티 플랫폼 |
| 타겟 | **모든 솔로 러너** + 러닝을 시작하고 싶지만 **동료가 없어 주저하는 예비 러너** |
| 톤앤매너 | 밝음 · 활발함 · 도파민 · 역동성 |
| USP | "혼자 달리는 자유는 그대로, 소속감은 덤으로" — 그룹 러닝의 부담 없이 연대감을 제공 |

### 네이밍 선정 과정 (요약)

- **1라운드**: 독립군 라임 계열 후보 발굴 → "달립군" 발견
- **2라운드**: 확장 브레인스토밍 (완주군 / 질주군 / 뛰겠군 / 가볼군 등) → 라임 완성도·유머·확장성 비교표 평가에서 "달립군" 우위 유지
- **3라운드**: 최종 검증 (탈락 사유 명시: 혼립군-발음 어색, 각자도생런-부정적 뉘앙스, 의병런-재밌지만 변질된 의미가 **솔로** 러너들을 대변하지 못함) → 대체 후보 없음 확인, **달립군 확정**

## 2. 캠페인 목표 / 핵심 메시지

### 캠페인 목표

1. 전국의 솔로 러너들에게 "혼자 달려도 우리는 연결되어 있다"는 소속감 부여 (솔로 러너 연합)
2. 동료가 없어 러닝을 망설이는 예비 러너에게 첫 발을 내딛을 용기 부여

### 핵심 메시지

> **"나는 혼자 달린다. 하지만 혼자가 아니다. 달립군이다."**

### CTA

> **"이 메시지를 보고 있다면, 당신이 바로 달립군이다."**

### 메시지 컨셉 노트

저항군 방송 스타일의 자기 선언 → 시청자 편입 구조.
"군(軍)" 세계관과 결합해, 메시지를 접하는 순간 시청자가 이미 연합의 일원이 되는 화법.
가입을 "권유"하는 대신 소속을 "선언"함으로써, 동료가 없어 주저하던 예비 러너의 심리적 장벽을 제거한다.

## 3. 영상 전체 구조

- 총 길이: **10초**
- 연출 컨셉: **원 컨티뉴어스 줌아웃** — 컷 전환 없이 카메라가 계속 뒤로 빠지며 상승하는 하나의 샷
- 의미 확장 구조: 개인(신발끈) → 공간(한강) → 영토(한반도)
- 조명 통일: 전 씬 "맑은 새벽 여명" (구름·비 없음)

```
씬 1 ──────▶ 씬 2 ──────▶ 씬 3
0~3초        3~7초         7~10초
클로즈업      미디엄→와이드    항공→위성 앵글
신발끈/기상    한강변 러닝     한반도 전경
        (컷 없음 · 연속 줌아웃)
```

### 파일명 규칙

`drg_s{씬번호}_{유형}_v{버전}.{확장자}`
예) `drg_s1_img_v1.png`, `drg_s2_vid_v2.mp4`, `drg_full_bgm_v1.mp3`

## 5. 프롬프트 수정 전/후 기록 (씬 3)

| 구분 | 내용 |
|---|---|
| 수정 전 | `Aerial zoom out from Han River showing many runners, ending in satellite view of Korea at dawn` |
| 수정 후 | `Aerial camera rapidly zooming out from a riverside path where many solo runners are running, each runner scattered and evenly spaced apart, not in groups, rising above the city into the sky, ending in a satellite view of the entire Korean Peninsula at dawn with the day-night terminator line crossing it, clear weather, one continuous pull-back shot, cinematic, 16:9` |
| 수정 이유 | ① 초기 프롬프트는 "many runners"만 명시해 **그룹 러닝처럼 생성될 위험** → "scattered, evenly spaced apart, not in groups"를 추가해 "솔로 러너 연합" 컨셉 보존 ② "Korea"만으로는 지도 형태가 모호하게 생성될 수 있어 "entire Korean Peninsula" + "day-night terminator line"으로 구체화 — 씬 1의 '동트는 새벽' 감성을 영토 스케일로 반복하는 서사적 통일성 확보 ③ "one continuous pull-back shot" 명시로 원 테이크 연출 강제 |

## 6. 사용 도구 목록

| 단계 | 도구 | 사용 목적 | 적용 씬 |
|---|---|---|---|
| 이미지 생성 | **Leonardo.ai** | 씬별 키프레임(시작/종료 프레임) 이미지 생성 — 클립 간 연속성 확보용 | 씬 1, 2, 3 |
| 비디오 생성 | **Kling** | image-to-video 변환, 연속 줌아웃 카메라 무빙 구현 | 씬 1, 2, 3 |
| 오디오 생성 | **Suno** | BGM 생성 (저음 빌드업 → 리듬 진입 → 클라이맥스, 10초 구조) | 전체 |
| 편집 | **CapCut** | 3개 클립 이어붙이기(원 테이크 연출), 자막·로고·CTA 오버레이, BGM/내레이션 믹싱 | 전체 |

### 도구 활용 전략 (원 테이크 연속성 확보)

1. Leonardo.ai로 각 씬의 **시작 프레임 = 이전 씬의 마지막 프레임**이 되도록 키프레임 생성
2. Kling에서 각 키프레임을 시작 이미지로 넣고 "continuous pull-back, no cuts" 프롬프트로 클립 생성
3. CapCut에서 3개 클립을 컷 티 안 나게 이어붙여 하나의 줌아웃 샷으로 완성
